# Arantes Carga — Atualizações

Este repositório distribui versões instaláveis do Arantes Carga.

- O código-fonte fica no repositório privado Arantes-Carga.

- Este repositório não deve conter código-fonte interno, bancos de dados, backups, logs ou dados operacionais da empresa.
